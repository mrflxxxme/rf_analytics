# 00. Видение и реестр решений

## Зачем

Видеть заранее, **что будет нужно в регионах РФ**, чтобы находить идеи для
коммерческих запусков раньше рынка. Объединяем в одну проверяемую картину
социально-экономический профиль региона, спрос (траты, поиск), плотность
предложения и внешний контекст: решения власти, климат, крупные проекты, ЧС.

## Для кого и в каком порядке

| Этап | Пользователь | Решение, которое он принимает |
|---|---|---|
| Сейчас | Автор (Кирилл) | Какие запуски предлагать себе и клиентам |
| Бета | Все, бесплатно | «Что нужно в моём регионе» / «где нужна моя ниша» |
| После гейта | Сети и франшизы (платят) | В какой регион идти с категорией X |
| Позже | МСП (бесплатная витрина), B2G, банки | Что открыть / что поддерживать / кредитный риск |

## Что продукт делает и чего не делает

**Делает:** ранжирует пары «регион/город × потребность» по вероятности, что
потребность реализуется в ближайшие 6–18 месяцев. К каждой паре показывает
раскладку факторов, уверенность, источники и связи на карте.

**Не делает:** не выбирает конкретное помещение или точку, не прогнозирует
выручку отдельного бизнеса, не даёт политических оценок, не выдаёт мнение
LLM за измерение.

## Реестр решений

Решения приняты в двух сессиях грилла: Г1 и Г2, 13.10.2026. Менять их можно
только явным решением с записью сюда: новая строка, старая помечается «заменено».

| # | Тема | Решение |
|---|---|---|
| D1 | Пользователь | Сначала автор как генератор идей; платят сети и франшизы; МСП получают бесплатную витрину; B2G позже |
| D2 | Территория | Субъект РФ (89) + города от 100 тыс. жителей |
| D3 | Горизонт | Прогноз на 6–18 мес.; до 3 лет — только качественные сценарии |
| D4 | Единица анализа | Своя таксономия потребностей; маппинг на ОКВЭД, поисковые запросы и категории трат; LLM-идеи поверх |
| D5 | Модель | Прозрачный индекс → веса калибруются на истории; раскладка факторов показывается всегда |
| D6 | Контекст | Реестр драйверов: LLM извлекает, человек подтверждает; только экономические формулировки |
| D7 | Freemium (цель) | Бесплатно — витрина; платно — досье, сравнение, алерты, экспорт. **Включается после гейта (D20)** |
