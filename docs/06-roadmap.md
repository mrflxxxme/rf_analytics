# 06. План на 10 недель

Порядок (D25): **сначала измеренные факты → потом прогноз и бэктест → потом
драйверы и ИИ → гейт**. Публичная версия появляется на неделе 3 и дальше
обновляется по мере готовности. Каждая задача закрывается по критерию приёмки,
а не по факту «код написан».

## Неделя 10. Гейт (D11)

- **Точность:** precision@top-20% ≥ B0 + 15 п.п. в среднем по периодам проверки.
- **Рынок:** 5 интервью с сетями и франшизами на живом продукте; ≥2 готовы на платный пилот.
- **До гейта** досье для клиентов собирается вручную в рамках консалтинга (D29).
- **Оба условия выполнены** → коммерческие функции по лестнице D29 (досье, подписка
  для сетей: сравнение, алерты, API, экспорт), снятие `noindex` с приложения.
- **Не выполнено** → проект остаётся открытым инструментом и источником контента;
  разбор причин записывается в `docs/07-risks.md`.

## Работа с ИИ-агентами

- Одна задача = одна ветка = один PR с критерием приёмки в описании.
- Агент перед PR прогоняет тесты и прикладывает доказательство приёмки
  (вывод тестов, фрагмент отчёта, скриншот).
- Методологические изменения (формулы, признаки, цели) — только через
  обновление `docs/03-methodology.md` в том же PR.
