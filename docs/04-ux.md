# 04. Интерфейс

Принцип: **карта — главный экран и полноценный участник данных** (D19). Всё,
что система знает или отвечает, отображается на карте: результаты запроса,
связи, драйверы. Карта — тоже способ спросить: выбор на карте сразу фильтрует
данные. Перегруз сдерживается жёсткими правилами (раздел «Ограничения»).

## Раскладка экрана

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [Регион → что нужно | Ниша → где нужна]   [ Спросить систему…        ⏎ ] │  ← режим + строка вопроса
│                                                        snapshot · бета ⓘ │
├───────────────┬──────────────────────────────────────────┬───────────────┤
│ ТОП-10        │                                          │ ДОСЬЕ         │
│ 1 ▮▮▮▮ 82 ●●○ │            КАРТА (на весь экран)         │ (выезжает     │
│ 2 ▮▮▮  76 ●●● │    заливка = одна метрика                │  по клику)    │
│ …             │    дуги / волны / импульсы драйверов     │               │
│ синхронно с   │                                          │               │
│ картой        │                                          │               │
├───────────────┴──────────────────────────────────────────┴───────────────┤
│ Слои: (Волны) (Миграция) (Драйверы)    ◀── 2019 ━━━━━━●━━ сейчас ┄┄ +18м │  ← слои + шкала времени
└──────────────────────────────────────────────────────────────────────────┘
```

На телефоне карта сверху, топ-10 — нижний лист, досье — полноэкранный лист.

## Два режима входа

1. **Регион → что здесь нужно.** Клик по региону или городу: карта приближается,
   топ-10 показывает потребности этого региона, заливка соседей — тот же
   скор для сравнения.
2. **Ниша → где она нужна.** Выбор потребности: заливка всей РФ по скору этой
   ниши, топ-10 — регионы, волны показывают, откуда идёт тренд.

## Карта как участник данных

| Что | Как выглядит | Данные |
|---|---|---|
| Скор пары | Заливка региона; насыщенность = уверенность (низкая — штриховка) | Модель (откалибровано / не откалибровано — видно на плашке) |
| Волны трендов | Анимированные дуги лидер → последователь; скорость ∝ лагу | Измерено и проверено (метод. п. 7) |
| Миграция | Дуги потоков, толщина = объём, цвет = сальдо | Измерено (Росстат) |
| Драйверы | Точка + расходящиеся кольца влияния, **пунктир** | Оценка (метод. п. 8), подпись «оценка» |
| Ответ на вопрос | Результат query-spec сразу отрисовывается на карте (заливка, выделение, связи) | Как у метрики |
| Шкала времени | Проигрывание истории (как росла ниша по регионам) и горизонт прогноза | Факты до «сейчас», прогноз после — другим стилем |

Визуальный словарь един для всего продукта: **сплошное = измерено,
пунктир/штриховка = оценка, приглушённое = мало данных**.

## Строка вопроса (D14)

- Пользователь пишет: «то же по городам Сибири с доходом выше медианы» или
  «где растёт спрос на уход за пожилыми и мало предложения».
- LLM переводит фразу в query-spec. Над результатом показываются **чипы
  распознанных фильтров** («Сибирский ФО», «доход > медианы», «города ≥100k»).
  Каждый чип можно убрать или изменить руками — это тот же конструктор.
- Если запрос не выразим через семантический слой, система так и отвечает
  и предлагает «Дообогатить».

## Дообогащение

Кнопка в досье и в ответе на вопрос: «добавить ключевые запросы», «посчитать
для города», «добавить категорию в разрез». Задача уходит в очередь (GitHub
Actions), пользователь видит статус и ожидаемое время. По готовности приходит
уведомление в интерфейсе, а результат появляется на карте. Лимиты — в
[AI-политике](05-ai-policy.md).

## Досье пары «регион × потребность»

Сверху вниз, от вывода к доказательствам:

1. Вывод одной фразой + скор + уверенность (с причинами).
2. Раскладка вклада факторов: горизонтальные бары по слоям, знак и величина.
3. Факты: ряды (число субъектов, выживаемость, траты) — мини-графики.
4. Почему разрыв: с какими регионами сравнивали и сколько «должно быть».
5. Связи: регионы-лидеры, миграция, драйверы (кликабельны → подсветка на карте).
6. Идеи для запуска (LLM, по кнопке, кешируются, помечены как «генерация»).
7. Источники, даты, snapshot, версия методологии; кнопки «Разрез» и «Дообогатить».
8. «Следующий шаг» (D31): одна рекомендация - Скаут или Born to Build с
   предзаполненным контекстом; только после того, как показаны вывод и скор.

## Ограничения против перегруза

- Одна метрика в заливке за раз. Не больше трёх слоёв связей, по умолчанию включён один.
- Топ-10, а не таблица. Полный список — по кнопке «ещё».
- Цифры — только скор (0–100) и уверенность. Остальное — в досье.
- Каждое состояние экрана — URL (режим, фильтры, слой, время, snapshot):
  им можно поделиться, и состояние воспроизводится.
- Плашка беты (D26) всегда доступна: «прогнозы не откалиброваны» или текущие
  метрики бэктеста.
- Рекомендаций других продуктов - не больше одной на экран; в подвале только
  подпись «от Кирилла Уклонского» и тонкая полоса экосистемы (D28, D31).

## Визуальный стиль

**Направление T2.4 — «прибор-радар», вариант A «Осциллограф»** (выбор владельца 19.10.2026, Э-65).
Нишемер — измерительный прибор: «сканируем страну — видно, где загорается малый бизнес».
Отклонены: «Атлас», «Ночь», «Сводка», копия uklonskiyk.ru, внутри «радара» — B «Самописец»
(светлая миллиметровка) и C «Развёртка» (карта во всю ширину с вращающимся лучом).

- **Палитра — общая с экосистемой** (uklonskiyk.ru): тёплый чёрный корпус `#151210`/`#100D0B`,
  крем `#F4F1EA`, чернила `#1A1611`, коралл `#FF4A2B`, приглушённый `#6E7B78`. **Форма — своя.**
- **Корпус прибора:** тёмный экран с сеткой 40 px; карта — в рамке с делениями по краям, шапка
  «Скан · …» и счётчик «N/N · дата» моно-шрифтом; справа — «Сигналы» (топ-5 регионов роста) и
  показания (субъекты, ниши, регионы, снимок).
- **Карта — настоящие границы субъектов** (Альберс 52°/64°/100°), заливка — одна метрика; поверх
  пунктирная градусная сетка (меридианы через 20°, параллели через 10°) и **импульсы** — расходящиеся
  кольца в регионах с самым быстрым ростом, подписаны номером строки «Сигналов». При
  `prefers-reduced-motion` импульсы стоят.
- **Шкала заливки** (одна во всём продукте): спад — холодный серо-зелёный, ноль сливается с корпусом,
  рост — накал коралла. Факты: классы `--r0…--r5` по границам −2/0/2/4/6 %; `/karta/`: `DIV` и `SEQ`
  в `web/src/model.ts` (последовательная — от корпуса к коралл → светлый коралл).
- **Типографика:** заголовки и числа — Fira Sans Condensed 800 (SIL OFL, `/fonts/`), подписи,
  значения таблиц и шкалы — моно (Cascadia/Consolas) капителью с разрядкой; надзаголовок — моно с
  «линейкой» делений слева. Текст — системный sans.
- **Показания на страницах фактов:** блок KPI — рамка с делениями сверху, число крупно, подпись моно;
  графики — пунктирные линии шкалы (0, ½, максимум). Страницы фактов — на креме, шапка и hero — корпус.
- Где лежит: факты — `etl/src/rf_etl/facts/assets/facts.css`, hero — `facts/heromap.py` и
  `render.Site.hero()`; `/karta/` — токены `web/src/styles.css`, цвета карты — `MapView.tsx`, шкалы —
  `model.ts`. Светлая тема `/karta/` — позже, по переключателю.

Реализация M1 (T2.2): `/karta/` — режимы «Ниша → где» и «Регион → что», одна метрика в
заливке (число активных субъектов МСП или его изменение за 12 месяцев), топ-10, шкала
времени по снимкам реестра с проигрыванием; состояние экрана — в URL. Цвет шкалы
фиксирован по всем периодам ряда, чтобы при проигрывании был виден рост. Скора и
уверенности до M2 нет: на M1 только измеренные факты (Э-51).
