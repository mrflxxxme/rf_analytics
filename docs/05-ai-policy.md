# 05. Политика использования ИИ

Правило: LLM применяется **только там, где без него ценности нет**, и
**никогда не производит цифры**, которые показываются как данные.

## Разрешённые операции

| # | Операция | Когда | Модель (D18) | Выход | Контроль |
|---|---|---|---|---|---|
| A1 | Извлечение драйверов | Еженедельно, batch | Отбор: Qwen3.6-35B-A3B; извлечение: DeepSeek-V4-Pro или GLM-5.1 (Cloud.ru) | JSON по схеме драйвера (метод. п. 8) | Статус `candidate` → автор подтверждает в админке → `confirmed` |
| A2 | Вопрос → query-spec | По запросу пользователя | Qwen3.6-35B-A3B (Cloud.ru) | JSON query-spec | Pydantic-валидация по белому списку семантического слоя; spec показывается чипами |
| A3 | Идеи для досье | По кнопке | DeepSeek-V4-Pro (Cloud.ru) | Текст со ссылками на факторы досье | Кеш по `(snapshot, r, n)`; метка «генерация» |

Работа на этапе разработки (составление таксономии, маппинг ОКВЭД ↔ запросы)
делается агентами вместе с автором один раз. Результат — файлы конфигурации
под контролем версий, в рантайме LLM для этого не вызывается.

## Запрещено

- Генерировать или «досчитывать» числовые значения, скоры, веса.
- Отвечать пользователю свободным текстом на аналитический вопрос в обход query-spec.
- Давать политические оценки: формулировки драйверов только экономические
  («строительство завода, +2000 рабочих мест»).
- Отправлять в LLM персональные данные (их в системе нет и быть не должно).

## Провайдеры

- Один OpenAI-совместимый клиент; маршрут «операция → провайдер → модель» в
  `config/llm.yaml`.
- Основной провайдер — **Cloud.ru Foundation Models**, только модели с
  размещением внутри РФ. Запасной — **DeepSeek API** напрямую: включается
  предохранителем после N ошибок подряд.
- Ключи переносит автор (из проекта wizard) в GitHub Secrets и `.env` сервера.

## Лимиты (публичная бета, D20/D26)

| Лимит | Значение (старт) |
|---|---|
| Общий бюджет LLM | ₽1500 / мес — жёсткая остановка; при 80% предупреждение автору |
| A2 «спросить» | 20 запросов / сутки / IP; 500 / сутки всего |
| Дообогащение | 3 задачи / сутки / IP; 30 / сутки всего; не больше 2 одновременно |
| A3 идеи | Только из кеша либо 5 генераций / сутки / IP |

При исчерпании — понятное сообщение; конструктор без LLM работает всегда.

## Журнал

Каждый вызов записывается: операция, модель, токены, стоимость, хеш входа,
валидность выхода. Тексты пользовательских вопросов хранятся 30 дней — для
улучшения перевода в query-spec, без IP.
