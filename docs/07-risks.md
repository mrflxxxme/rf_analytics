# 07. Критический разбор и риски

## Противоречия во вводных и как они сняты

| Противоречие | Решение |
|---|---|
| «Максимально полная аналитика» против «дёшево и быстро» | Полнота считается покрытием **слоёв модели** (предложение, спрос, деньги, структура, контекст), а не числом источников: 1–2 лучших источника на слой |
| «Интерактивно уточнять и дообогащать» против «минимум ИИ» | Конструктор query-spec детерминирован; LLM только переводит фразу в spec, который виден пользователю; дообогащение — задача сборщика, а не генерация (D14) |
| «Проверяемо» против «нет надёжного факта» | Явная целевая переменная (D15) + бэктест вне выборки + публичные метрики |
| «Публично сразу» против «не публиковать непроверенное» | Бета с плашкой калибровки, сначала только измеренные факты; индексируется только статический слой фактов, приложение с прогнозами и API - `noindex` до гейта (D25, D26, D27) |
| «Карта как участник данных» против «не перегружать» | Единый визуальный словарь (измерено / оценка / мало данных), одна метрика и ≤3 слоя (раздел UX) |

## Риски

| # | Риск | Вероятность | Влияние | Митигация | Сигнал раннего обнаружения |
|---|---|---|---|---|---|
| R1 | Модель не обгоняет «рост прошлого года» на 15 п.п. | Средняя | Высокое | Честный гейт; продукт остаётся инструментом мониторинга фактов | Метрики v0 на неделе 5 |

| R3 | Геоблок или смена формата у госисточников | Высокая | Среднее | Скачивание с сервера в РФ, пробник T1.1, флаги устаревания, алерт при падении fetcher | Падение fetcher |
| R4 | Росстат закрывает показатели | Средняя | Среднее | Флаг «устарел», замена на альтернативу (ЕМИСС ↔ ЦБ ↔ hh) | Дата последней публикации |
| R5 | Короткая история Вордстата / нет доступа к API | Высокая | Низкое | Поиск — отдельный контур, в скор не входит (D16) | Ответ на заявку |
| R6 | Множественные сравнения дают ложные волны | Высокая без контроля | Высокое | Бутстреп + FDR + проверка вне выборки | Доля связей, не подтвердившихся вне выборки |
| R7 | Публичная бета сжигает бюджет LLM или нагружает сервер | Средняя | Среднее | Жёсткие лимиты, кеш, лимиты памяти контейнеров | Журнал вызовов, 80% бюджета |

| R9 | Чувствительность контекста (политика, СВО, выплаты) | Средняя | Высокое | Только экономические формулировки, подтверждение человеком, без оценок | Ревью кандидатов |

| R12 | Соло-разработка с агентами расползается по объёму | Высокая | Среднее | Критерии приёмки, этапы M1–M3, всё вне плана — в бэклог | Срыв M1 к концу недели 3 |

## Открытые вопросы (решаются по ходу)

- Название продукта и его домен (`radar` - рабочее имя): выбираются до M1, задача T1.0 (D28).
- Состав 5–10 пилотных регионов для городов и драйверов (предложение:
  регионы, где у автора есть проекты, + контрастные по профилю).
- Условия доступа к API Вордстата и hh.ru (T1.1).
- Есть ли в открытом доступе матрица межрегиональной миграции «откуда → куда» (T1.1).
